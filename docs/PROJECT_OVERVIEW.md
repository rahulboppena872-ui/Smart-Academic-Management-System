# Project Overview

## Problem
Academic institutions often manage timetable, faculty availability, attendance, leave, substitutions and payroll separately. A sudden absence can disrupt a class and delay communication.

## Solution
A centralized role-based platform for Admin/Director, Faculty and Students. Faculty can mark attendance and submit normal/emergency leave. Admin approves leave. When a timetable entry is affected, an explainable AI recommendation engine ranks conflict-free replacement faculty and the system notifies the replacement and affected students after approval.

## Security
Salary and faculty-private attendance are restricted to authorized roles. Students only see their class information.

## Future
Face recognition attendance, email/SMS/WhatsApp, ML-trained substitution model, payroll automation, calendar sync, AI chatbot and mobile app.
